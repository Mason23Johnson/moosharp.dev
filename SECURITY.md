## Reporting a Vulnerability

If you discover a security vulnerability, please do **not** open a public issue.

Use GitHub's private vulnerability reporting feature for this repository if it is enabled.

If needed, you may also contact:

**masonbjohnson.college@gmail.com**

Please include:
- A short description of the issue
- Steps to reproduce it
- The potential impact
- Any suggested mitigation or fix, if known

I will review the report as quickly as possible and work on a fix if the report is valid.

## Scope

Please report issues such as:
- Exposed secrets, tokens, or credentials
- Authentication or authorization problems
- Dependency vulnerabilities with real impact
- XSS, injection, or code execution issues
- Dangerous deployment or configuration mistakes

## Out of Scope

The following are generally out of scope unless they have clear security impact:
- Typos or wording problems
- Styling or UI-only bugs
- Missing best practices without exploitability
- Scanner-only reports with no real impact
